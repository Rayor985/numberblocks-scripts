# 第 17 集 Ep 17：Pattern Palace｜图案宫殿

**剧情简介 Synopsis:** 图案宫殿的大门上藏着规律：红、蓝、红、蓝……接下来是什么？ / The Pattern Palace gates hide a pattern: red, blue, red, blue… what comes next?

**角色 Characters:** 一号 One、二号 Two

**剧本 Script:**

*（图案宫殿大门，门上有颜色图案 / The Pattern Palace gates, with a colour pattern on them）*

**One（一号）:** Look! Red, blue, red, blue… what's next? / 看！红、蓝、红、蓝……接下来是什么？

**Two（二号）:** Red! The pattern repeats: red, blue, red, blue! / 红色！规律在重复：红、蓝、红、蓝！

*（大门打开 / The gates open）*

**One（一号）:** Circle, square, circle, square… circle! / 圆、正方形、圆、正方形……圆！

**Two（二号）:** You found the pattern! Circle, square, over and over! / 你找到规律啦！圆、正方形，不断重复！

*（宝座上有数字图案 / A number pattern on the throne）*

**One（一号）:** 1, 2, 1, 2… 1! / 1、2、1、2……1！

**Two（二号）:** Patterns are everywhere in the Pattern Palace! / 图案宫殿里到处都是规律！

**One（一号）:** Red, blue… 1, 2… I love patterns! / 红、蓝……1、2……我爱找规律！

*（宫殿亮起彩灯 / The palace lights up）*

**All（大家）:** Pattern Palace — pattern perfect! / 图案宫殿——规律完美！
