# 第 3 集 Ep 3：The Numberblocks Express｜数字快车

**剧情简介 Synopsis:** 数字快车出发啦！乘客上上下下，看看 5 有多少种分法。/ All aboard the Numberblocks Express! Passengers hop on and off — how many ways can you make five?

**角色 Characters:** 列车长 Conductor、一号 One、四号 Four、五号 Five、二号 Two、三号 Three

**剧本 Script:**

*（火车站，汽笛响起 / At the station, the whistle blows）*

**Conductor（列车长）:** All aboard the Numberblocks Express! / 数字快车就要出发，请上车！

*（一号和四号上车 / One and Four hop on）*

**One（一号）:** One plus four… / 一加四……

**Four（四号）:** …equals five! / ……等于五！

*（闪光，"1, 2, 3, 4, 5！" / Flash! "1, 2, 3, 4, 5!")*

**Five（五号）:** I'm Five! All aboard! / 我是五号！请上车！

*（一号四号下车，二号三号上车 / One and Four hop off; Two and Three hop on）*

**Two（二号）:** Two plus three… / 二加三……

**Three（三号）:** …equals five, too! / ……也等于五！

**Five（五号）:** Different friends, same Five! / 不同的朋友，一样的五！

**Conductor（列车长）:** 🎵 One and four, two and three, / 🎵 一加四，二加三，

🎵 So many ways to make five, you see! / 🎵 变成五的方法真不少！

🎵 Hop on, hop off, here we go, / 🎵 上车下车，出发啦，

🎵 The Numberblocks Express — all aboard, ho! / 🎵 数字快车——请上车！

**All（大家）:** Five! Five! The Numberblocks Express! / 五！五！数字快车！
