# 第 30 集 Ep 30：Step Squads｜台阶小队

**剧情简介 Synopsis:** 台阶小队集合！一级一级往上加：1、3、6、10、15——三角形数！ / The Step Squads assemble! Adding step by step: 1, 3, 6, 10, 15 — the triangle numbers!

**角色 Characters:** 一号 One、三号 Three、六号 Six、十号 Ten、十五 Fifteen

**剧本 Script:**

*（大家摆台阶 / Everyone builds staircases）*

**One（一号）:** I'm the first Step Squad! Just one step: 1! / 我是第一支台阶小队！只有一级：1！

**Three（三号）:** Add two more steps: 1 + 2 = 3! / 再加两级：1 + 2 = 3！

*（三号摆成两级台阶 / Three builds two steps）*

**Six（六号）:** Add three more: 1 + 2 + 3 = 6! / 再加三级：1 + 2 + 3 = 6！

**Ten（十号）:** Add four more: 1 + 2 + 3 + 4 = 10! / 再加四级：1 + 2 + 3 + 4 = 10！

**Fifteen（十五）:** Add five more: 1 + 2 + 3 + 4 + 5 = 15! / 再加五级：1 + 2 + 3 + 4 + 5 = 15！

*（五支台阶小队排排站 / The five Step Squads line up）*

**One（一号）:** 1, 3, 6, 10, 15! / 1、3、6、10、15！

**Six（六号）:** Each squad is a triangle of steps! / 每支小队都是三角形的台阶！

**Ten（十号）:** 1, 3, 6, 10, 15 — the step numbers! / 1、3、6、10、15——台阶数！

**All（大家）:** Step squads — step by step by step! / 台阶小队——一步一步又一步！
