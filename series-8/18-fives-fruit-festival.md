# 第 18 集 Ep 18：Five's Fruit Festival｜五号水果节

**剧情简介 Synopsis:** 水果节用象形图摆出最受欢迎的水果，一眼就能比出多少。 / The fruit festival uses a pictogram, so everyone can see which fruit is most popular at a glance.

**角色 Characters:** 一号 One、二号 Two、五号 Five、六号 Six、七号 Seven、八号 Eight、九号 Nine

**剧本 Script:**

*（广场上挂起水果节的彩旗 / Festival flags hang across the square）*

**Five（五号）:** Every fruit picture stands for one vote. / 每张水果图片代表一票。

**Two（二号）:** Apples have four pictures. / 苹果有四张图片。

**Seven（七号）:** Oranges have six—six votes! / 橙子有六张——六票！

**Eight（八号）:** Pears have two, so oranges win this round. / 梨只有两张，所以这一轮橙子赢了。

**Nine（九号）:** The tallest column is easiest to see. / 最高的一列最容易看清。

*（果篮被抬上最高的台子 / The winning basket is lifted onto the top step）*

**Six（六号）:** A pictogram turns lots of little votes into one clear picture. / 象形图把许多小票变成一张清楚的图。

**All（大家）:** Sample, count, compare: happy fruit festival! / 取样、计数、比较：水果节快乐！
