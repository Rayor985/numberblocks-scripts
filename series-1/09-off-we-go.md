# 第 9 集 Ep 9：Off We Go｜出发啦

**剧情简介 Synopsis:** 五号带着朋友们去田野森林大冒险：排好队，一、二、三、四、五！/ Five leads a rhyming romp through field and forest: line up — one, two, three, four, five!

**角色 Characters:** 一号 One、二号 Two、三号 Three、四号 Four、五号 Five

**剧本 Script:**

*（田野边，大家整装待发 / At the edge of the field, everyone is ready）*

**Five（五号）:** Off we go! Follow me! / 出发啦！跟我来！

**One（一号）:** Through the field! / 穿过田野！

**Two（二号）:** Through the forest! / 穿过森林！

**Five（五号）:** Line up in order! One, two, three, four, five! / 按顺序排队！一、二、三、四、五！

*（大家排成一队 / Everyone lines up in order）*

**Three（三号）:** Uh oh! Someone's missing! Who is it? / 糟糕！少了一个！是谁？

**Four（四号）:** One, two, three… five! Four is missing! / 一、二、三……五！少了四！

**Five（五号）:** Come back, Four! Now we're complete! / 四快回来！这下齐了！

**All（大家）:** 🎵 Off we go, off we go, / 🎵 出发啦，出发啦，

**All（大家）:** 🎵 One, two, three, four, five — off we go! / 🎵 一、二、三、四、五——出发啦！

**Five（五号）:** What an adventure! / 多棒的冒险！
